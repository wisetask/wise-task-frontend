# change-password

Смена пароля вошедшим пользователем: текущий пароль, новый и повтор.

```vue
<ChangePasswordForm />
```

Форма сама проверяет поля, отправляет `changePassword` и после успеха пишет «Пароль изменён» и очищает поля. Один глаз показывает все три поля, под новым паролем полоска надёжности (`passwordStrength` из `shared/lib`), при включённом Caps Lock — подсказка.

- `lib/passwordChange.ts` — чистые функции с тестами: `checkPasswordChange` (ошибки под полями: пустой текущий, новый короче 3 символов или совпадает с текущим, повтор не совпадает) и `changePasswordErrorMessage` (текст ошибки бэка).
- `model/useChangePassword.ts` — отправка. Мутация уходит с `context: { keepSession: true }`: неверный текущий пароль бэк отдаёт как `UNAUTHORIZED`, и без пометки клиент разлогинил бы человека (см. `shared/api/session.ts`). HTTP 401 на истёкший токен по-прежнему завершает сессию.
