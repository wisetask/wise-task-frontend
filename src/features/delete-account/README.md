# delete-account

Удаление своего аккаунта с подтверждением почтой.

```vue
<DeleteAccountSection :email="user.email" @deleted="router.push('/')" />
```

Сначала видна только кнопка «Удалить аккаунт…». По ней открывается панель с полем: «Удалить навсегда» становится активной, только когда в поле введена своя почта (`isDeleteConfirmed`: регистр и пробелы по краям не важны). После удаления фича сама вызывает `userStore.logOut()`, а событие `deleted` говорит странице, куда перейти.

- `lib/deleteConfirm.ts` — чистые функции с тестами: подтверждение и текст ошибки. Текст ошибки бэка не показываем.
- `model/useDeleteAccount.ts` — мутация `deleteProfile` для своего `id` и выход.

Бэк (`wise-task-profile`) удаляет только сам профиль; что происходит с решениями и задачами человека в других сервисах, уточняется у бэка — от этого зависит текст предупреждения.
