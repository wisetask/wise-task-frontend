# auth-by-email

Вход и регистрация по почте и паролю.

```vue
<SignInForm @success="onSuccess" />
<SignUpForm @success="onSuccess" />
```

Формы сами отправляют запрос, показывают ошибку и после успеха сохраняют пользователя через `useUserStore().logIn`. Событие `success` значит, что пользователь вошёл; куда перейти дальше, решает страница. Для этого есть `getRedirectPath(route.query.redirect)`: вернёт адрес из `?redirect=`, если он внутри сайта, иначе `/`.

Если нужна своя форма, логика доступна отдельно: `useSignIn()` и `useSignUp()` возвращают функцию отправки, `loading` и `error`.

## Ошибки

Текст ошибки для формы делает `getAuthErrorMessage` (`lib/getAuthErrorMessage.ts`) по `extensions.classification` из ответа бэка:

- нет ответа от сервера - «Нет связи с сервером»;
- на входе `NOT_FOUND`, `UNAUTHORIZED`, `BAD_REQUEST` - «Неверная почта или пароль». Не уточняем, что именно не так, чтобы по ответу нельзя было узнать, зарегистрирована ли почта;
- на регистрации `BAD_REQUEST` - текст бэка как есть, например «Пользователь с данной электронной почтой уже существует»;
- остальное - «Что-то пошло не так, попробуйте позже». Текст сбоя бэка пользователю не показываем.
