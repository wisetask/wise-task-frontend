# Условия задачи

Фича добавляет проверки по плагинам к задаче. Родительский компонент хранит массив `TaskCondition[]` и передаёт его в `TaskConditionsEditor` через `v-model`.

Подключите `PluginPicker` с каталогом `plugins` и видом графа `graphType`. В обработчике `pick` обновите массив через `addCondition(conditions, conditionFromPlugin(plugin))`. Пример подключения доступен на `/ui-kit`.

- `conditionFromPlugin` создаёт условие с начальными значениями.
- `addCondition`, `removeCondition`, `moveCondition` и `changeCondition` возвращают новый массив.
- `conditionError` возвращает первую ошибку условия или пустую строку. Второй аргумент позволяет проверить отдельное поле.
- `toPluginInfoInput` формирует данные для бэка и проставляет `order` с единицы.
- `pluginFitsTask` проверяет совместимость плагина с видом графа.

Значения свойств «Выполняется» и «Не выполняется» взяты из ТЗ. Их формат нужно подтвердить с бэкендом. До уточнения `GRAPH_NEW_GRAPH` и `GRAPH_STRING` редактируются как свойства.

Для реального каталога вызовите `usePlugins()` в родительском компоненте. Он возвращает `plugins`, `loading` и `error`, запрашивает `getAllPlugins` с фильтром `isValid: true` и догружает страницы по `hasNext`. На `/ui-kit` по умолчанию доступны тестовые плагины, а кнопка «Загрузить каталог с сервера» позволяет проверить запрос.
