# Нормализация графа

`normalizeGraph(graph)` возвращает новый граф, меняя только координаты вершин.
Компоненты размещаются слева направо; расстояние между вершинами — не менее 60 px.

Раскладки: цепь — линия, цикл и остальные графы — круг, звезда — вокруг центра,
дерево — по уровням, двудольный граф — две колонки.

`detectType(component)` определяет тип, `splitIntoComponents(graph)` возвращает
компоненты связности. Направление рёбер не учитывается. Петли и пустой граф поддерживаются.

`layoutTree(graph, rootId)` размещает вершины по уровням. Если переданный `rootId`
есть в графе, эта вершина занимает верхний уровень. Если передан `null`, параметр
пропущен или вершина отсутствует, корнем становится вершина с наибольшей степенью.

`arrangeComponents(graph, layout)` применяет функцию `layout` к каждой компоненте
связности и размещает компоненты слева направо с промежутком в 100 единиц.
`normalizeGraph` использует её, чтобы подобрать раскладку по типу каждой компоненты.

Редактор графа использует эту фичу для команд «Автоматически», «По кругу»,
«По уровням» и «В две доли». Для раскладки по уровням редактор передаёт в
`arrangeComponents` вызов `layoutTree` с идентификатором выделенной вершины.
