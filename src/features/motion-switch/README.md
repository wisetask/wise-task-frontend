# motion-switch

Кнопка `MotionToggle` в шапке рядом со сменой темы: «Спокойный режим». Выключает анимации на всём сайте и убирает украшения: живой граф и созвездие в шапке списка задач, печатающуюся подсказку, искры, вспышки, мини-графы при наведении, плавную смену страниц, полоску загрузки под шапкой и раскрытие карточки в задачу. Полезное (поиск, картинка графа, сворачивание условия, случайная задача) остаётся. Для тех, кому волны, искры и прыгающие вершины мешают.

```ts
import { MotionToggle } from "@/features/motion-switch";
```

Нажатие вызывает `setMotionOff` из `@/shared/lib/motion`: на `<html>` ставится `data-motion="off"` (или `"on"`), выбор сохраняется в `localStorage` под ключом `wisetask.motion`. Скрипт в `index.html` читает этот ключ до отрисовки страницы, поэтому после перезагрузки анимации не успевают мигнуть.

Когда анимации выключены, иконка-волна перечёркнута красной линией, а в подсказке написано «Выключить спокойный режим». Что именно выключается — в README `shared/lib`.
