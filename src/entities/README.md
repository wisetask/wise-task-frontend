# entities

Сущности предметной области: `graph`, позже `user` и `task`.

`graph` — единая модель графа для всего приложения. Типы в `model/types.ts`, операции (добавить, удалить, переместить) в `model/operations.ts`. Операции не меняют переданный граф, а возвращают новый — это упрощает undo/redo.

Можно импортировать только из `shared`.
