# relation

Бинарные отношения для модуля «Отношения»: отношение на `n` элементах хранится как матрица `n × n` (`Matrix = number[][]`), `matrix[i][j] !== 0` — пара `(i, j)` есть в отношении. Внутри элементы нумеруются с 0, в интерфейсе их показывают с 1.

Только логика, без интерфейса. Граф для редактора из матрицы собирается уже в виджете модуля.

## Умножение и степени

`multiply(a, b, kind)` и `power(a, n, kind)`, где `kind`:

- `"classic"` — обычное умножение. Клетка `(i, j)` степени `N` — сколько путей длины `N` ведут из `i` в `j`;
- `"logical"` — 0 и 1: есть ли хоть один путь длины `N`;
- `"tropical"` — max-plus: наибольший вес пути длины `N`, 0 — пути нет. Пока все веса равны 1, это просто `N` там, где путь есть.

`multiplyCell(a, b, i, j, kind)` считает одну клетку — пригодится для пошаговой демонстрации. `pathsOfLength(matrix, from, to, N)` перечисляет сами пути (списки вершин), чтобы подсвечивать их на графе при наведении на клетку; их количество всегда равно клетке классической степени.

## Генерация

`generateRelation(size, pairs, kind, random)` — случайное связное отношение на `size` элементах (от 3 до 9) с `pairs` парами:

- `"any"` — любое, петли можно;
- `"symmetric"` — вместе с `(i, j)` есть `(j, i)`; пара `i–j` считается один раз, петли можно;
- `"antisymmetric"` — нет одновременно `(i, j)` и `(j, i)` при `i ≠ j`, петли можно;
- `"asymmetric"` — как антисимметричное, но без петель.

Пар должно быть от `minPairs(size)` (иначе граф не будет связным) до `maxPairs(size, kind)`, иначе вернётся `null`. `random` можно не передавать; в тестах туда подставляется генератор с зерном, чтобы результат повторялся.

## Свойства

`isReflexive`, `isSymmetric`, `isAntisymmetric`, `isAsymmetric`, `isTransitive`, `matchesKind`, `isConnected` (связность графа отношения, направление рёбер не учитывается).
