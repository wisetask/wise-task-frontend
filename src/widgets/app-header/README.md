# app-header

Шапка сайта: логотип, разделы и кружок с инициалами, по клику на который открывается меню пользователя. Сама ничего не загружает: пользователя получает снаружи.

```vue
<AppHeader :user="user" @sign-out="onSignOut" />
```

- `user` — `{ firstName, lastName, email, role }` или `null`, если пользователь не вошёл (тогда вместо аватара кнопка «Войти»).
- `sign-out` — пользователь нажал «Выйти» в меню. Что делать дальше, решает тот, кто подключил шапку.

Подключена в `app/layouts/AppLayout.vue`, поэтому есть на всех страницах, кроме входа и регистрации.

## Какие разделы видит какая роль

| Роль           | Разделы                           |
| -------------- | --------------------------------- |
| гость (`null`) | Треки, Задачи, Библиотека графов  |
| `USER`         | то же + Мои решения               |
| `AUTHOR`       | то же + Конструктор задач         |
| `ADMIN`        | всё, а ещё Плагины и Пользователи |

Раздел подсвечивается на своей странице и на вложенных (`/tasks/15` подсветит «Задачи»). Для этого своя функция `isSectionActive`, а не класс `router-link-active`: он не сработает, если `/tasks` и `/tasks/:id` объявлены как соседние маршруты.

## Меню пользователя

Закрывается по клику мимо, по `Esc` и после выбора пункта. Слушатели клика и `Esc` живут в `AppHeader.vue`, а не в `UserMenu.vue`: так клик по самому аватару не закрывает меню и тут же не открывает его снова.

## Где что

- `ui/AppHeader.vue` — шапка;
- `ui/UserMenu.vue` — выпадающее меню (имя, почта, роль, «Профиль», «Выйти»);
- `lib/sections.ts` — какие разделы показать, подпись роли, инициалы, подсветка раздела; рядом тесты `lib/sections.test.ts`.

Высота шапки и тень меню — переменные `--header-height` и `--shadow-popover` в `src/app/styles.css`.
