# relation-matrix

Сетка матрицы отношения для модуля «Отношения»: строки и столбцы подписаны 1..n, клетки можно только показывать или заполнять. Считает и проверяет ответы не сама: правильные значения ей передаёт страница (обычно `power` из `@/entities/relation`).

Показать матрицу:

```vue
<RelationMatrix title="A" :values="relation" @hover="onHover" />
```

Дать заполнить:

```vue
<RelationMatrix
  v-model:answers="answers"
  title="A²"
  editable
  :expected="power(relation, 2, 'classic')"
  :show-result="true"
  :highlight="hovered"
  @hover="onHover"
/>
```

- `answers` — что ввёл студент, `(number | null)[][]`, пустая клетка — `null`. Начальное значение — `emptyAnswers(n)`.
- `expected` и `show-result` — если оба заданы, клетки подсвечиваются зелёным или красным сразу при вводе (режим тренировки). Без `show-result` заполненные клетки просто серые (режим проверки, когда ответ показывают по кнопке).
- `highlight` — какую клетку обвести (например, текущий шаг в демонстрации).
- `hover` — клетка под мышью или в фокусе, `{ row, col }` с нуля, `null`, когда мышь ушла с таблицы. По ней страница подсвечивает пути на графе (`pathsOfLength`).

В клетку вводятся только целые неотрицательные числа, остальное просто не печатается. Стрелки переводят фокус между клетками, Enter — на следующую клетку (в конце строки — на начало следующей).

Для страницы есть ещё `isSolved`, `countFilled` и `countMistakes` — заполнена ли матрица верно, сколько клеток заполнено и сколько с ошибкой.

Файлы:

- `ui/RelationMatrix.vue` — сама сетка;
- `lib/cells.ts` — разбор ввода, состояние клетки, переход стрелками, подсчёты. Рядом тесты, а `ui/RelationMatrix.test.ts` проверяет компонент целиком в `happy-dom`.

Посмотреть вживую можно на странице `/ui-kit`, раздел «Матрица отношения».
