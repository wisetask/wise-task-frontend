# task-view

Задача на граф глазами студента: как её показать и как показать результат проверки. Используют страница решения задачи (`pages/task`) и просмотр решения (`pages/solution`).

## Что внутри

- `TaskCondition` (`ui/TaskCondition.vue`) — левая колонка с условием: категория (плашкой), автор, название, описание, подсказки, «Граф задачи» (`TaskGraphPreview`) и «Что проверяется» (нумерованный список в кружках). Пропсы: `view` (`TaskView`), `hints` (строки), необязательные `marks` (что отметить в «Что проверяется»: `pluginId` → `"ok"` или `"fail"`) и `checking` (идёт проверка — номера мигают).
  - Колонка сворачивается кнопкой со стрелкой в правом верхнем углу: остаётся узкая полоса с вертикальной надписью «Условие · название», клик по ней разворачивает обратно. Свёрнута ли колонка, запоминается в `localStorage` (`wisetask.task.conditionOpen`, `lib/conditionPanel.ts`) — одинаково для страницы задачи и просмотра решения. Уже 800px колонка встаёт над редактором и сворачивается в полосу высотой 52px. Слот `top` — строка над категорией (страница задачи кладёт туда «← Все задачи»), слот `bottom` — блок в самом низу (там «Мои попытки»).
  - Анимации: при открытии блоки условия выезжают по очереди, номера в «Что проверяется» выпрыгивают, по плашке категории пробегает блик, у подсказок «вспыхивает» значок. Ссылки, номера проверок, кнопка сворачивания и холст графа отзываются на наведение. Выключаются переключателем анимаций.
  - Ссылки в описании (`https://…`) показываются короткими плашками вида «ru.wikipedia.org › Степень вершины» и открываются в новой вкладке, полный адрес — во всплывающей подсказке. Разбивку текста на куски и подпись ссылки делают `descriptionParts` и `linkLabel` (`lib/description.ts`): адрес раскодируется, `_` становятся пробелами, длинный хвост обрезается, точка или запятая после ссылки в неё не попадают.
- `TaskGraphPreview` (`ui/TaskGraphPreview.vue`) — «Граф задачи» в условии. Не редактор, а лёгкая картинка: граф целиком вписан в рамку (`previewBox`, маленький граф не раздувается), без кнопок масштаба. Сверху плашки «6 вершин», «7 рёбер», «неориентированный», «взвешенный» (`graphSummary`). На рёбрах веса и подписи, у ориентированных — стрелки, встречные дуги разведены, петли нарисованы (`previewEdges`). При появлении рёбра прорисовываются, вершины выскакивают по очереди. Наведение на вершину подсвечивает её, соседей и рёбра (по ним бежит огонёк), остальное тускнеет, а под картинкой пишется «Вершина 2: степень 3, соседи 1, 3, 5» (`vertexCaption`); клик закрепляет вершину. Справа сверху кнопки: «Открыть крупно» (окно на весь экран с обычным холстом, масштабом и `Esc`) и «Скачать PNG».
- `GraphMiniature` (`ui/GraphMiniature.vue`) — маленькая картинка графа без интерактива. Пропсы: `graph` (`Graph` или `null`), `loading` (мерцающая заготовка), `large` (крупно, с подписями вершин и весами, рёбра прорисовываются). Пустой граф не показывается. Используется в карточках списка, в предпросмотре и в «Моих попытках». `loadThumbGraph(taskId)` тоже экспортируется: одна загрузка на задачу, ответы общие.
- `TaskGraphThumb` (`ui/TaskGraphThumb.vue`) — мини-граф для карточки в списке задач, 96×64, без подписей. Пропс `taskId`. Граф грузит отдельным маленьким запросом `GetTaskGraph` (`api/getTaskGraph.ts`), только когда карточка рядом с экраном, и запоминает ответ (`lib/thumbGraph.ts`). Список задач от этого запроса не зависит: если граф не пришёл или бэк ответил ошибкой, мини-графа просто нет. Пока грузится — мерцает, если граф пустой или не загрузился — ничего не показывает.
- `CheckResultNotice` (`ui/CheckResultNotice.vue`) — карточка с результатом проверки. Слева значок: кружок и галочка (или крестик) прорисовываются. Справа заголовок, строка под ним и список непройденных проверок, пункты выезжают по очереди. Верная карточка зелёная, по ней пробегает блик; неверная красная и один раз встряхивается. Слот `actions` — кнопки под текстом (страница задачи кладёт туда «Следующая задача»). Пропсы: `result` (`CheckResult`), необязательные `successTitle` («Верно!»), `successText` («Все проверки пройдены.»), `failureTitle` («Пока неверно»), `note` (жёлтая строчка-шутка внизу, при смене текста покачивается) и `closable` (крестик, событие `close`). Под заголовком неверного ответа — `failureSummary`: «Вот что не так:» или «Не прошли 2 проверки». Где стоит карточка, решает страница.
- `lib/taskView.ts` — задача с бэка → `TaskView`:
  - `toTaskView(task, loadedGraph)` — граф через `fromBackendGraph`, правила `rule` → правила редактора (`rulesFromBackend`, `isEdit` включает и добавление, и подписи), условия → список проверок (`checkText` даёт только название проверки, без значения). Граф без вершин считается отсутствующим (так в базе хранятся задачи на построение графа). Возвращает `null` для задач на код;
  - `answerStartsFromTask`, `startAnswer`, `canPickDirection` — с чего начинается ответ: с копии графа задачи, если он есть, иначе с пустого поля;
  - `taskHints` — подсказки студенту;
  - `graphToLoad(graph)` — id графа, если бэк прислал его только ссылкой (без вершин).
- `lib/graphPreview.ts` — расчёты для `TaskGraphPreview` без Vue: `previewBox`, `previewEdges`, `graphSummary`, `closeIds`, `vertexCaption`, задержки появления;
- `lib/checkResult.ts` — `checkMarks` (отметки для «Что проверяется»; в `CheckResult` теперь есть `failedPlugins`), `failedChecksText` (склоняет «проверка»), `failureSummary`; ответ проверки → `CheckResult`: `toCheckResult` берёт текст ошибки у автора задачи (`mistakeText` условия), иначе `pluginMessage`, иначе «Не выполнено: <плагин>»; для чисел и строк пишет, что получилось у студента; при `isHiddenMistake` оставляет только первую ошибку.
- `lib/loadGraph.ts` — `loadFullGraph(graph)`: если граф пришёл только ссылкой, догружает его запросом `getGraphById` (`api/getGraph.ts`), иначе возвращает как есть. `tryLoadFullGraph` делает то же, но вместо ошибки возвращает `null`: бывает, что ссылка ведёт на граф, которого в сервисе графов нет.

После изменения запроса в `api/getGraph.ts` нужно перезапустить `npm run codegen`.
