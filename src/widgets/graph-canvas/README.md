# graph-canvas

Холст для рисования графа на SVG. Подключается через `v-model:graph`:

```vue
<GraphCanvas v-model:graph="graph" @before-change="history.record" />
```

Что умеет:

- клик по пустому месту — новая вершина;
- клик по вершине, потом по другой — ребро; дважды по одной вершине — петля;
- перетаскивание вершины мышью;
- правый клик по вершине или ребру — удалить;
- `Esc` — снять выделение.

В ориентированном графе у рёбер есть стрелки, а встречные рёбра `a → b` и `b → a` рисуются дугами, чтобы не накладывались.

Событие `before-change` приходит с графом **до** изменения, один раз на действие. При перетаскивании — один раз в момент, когда вершину сдвинули, а не на каждый пиксель. Сюда подключается история (undo/redo).

Расчёт линий, дуг и петель — в `lib/geometry.ts`, тесты рядом. Цвета берутся из CSS-переменных в `src/app/styles.css`.
