# task-constructor

Страница `/constructor` — «Конструктор задач»: здесь автор собирает задачу на граф. Пока это каркас: задача живёт только в памяти страницы, на бэк не сохраняется и после перезагрузки пропадает. Кнопка «Создать задачу» неактивна, пока не подключим вход и мутацию `createTaskGraph`.

## Вкладки

- **Основное** — название, категория, описание, вид графа и галочки: «Граф задан», «Показывать только первую ошибку» (`isHiddenMistake` на бэке), «Публичная задача». Внизу список того, что ещё не заполнено (`draftProblems`).
- **Граф** — есть, только если стоит «Граф задан». Здесь автор рисует граф в обычном `GraphEditor` (сам автор может всё) и галочками `GraphRulesForm` решает, что с этим графом сможет делать студент. Если снять «Граф задан», нарисованный граф не теряется: вкладка просто пропадает, а при сохранении граф не отправится.
- **Условия** — пока заглушка. Сюда встанут проверки решения по плагинам (задача T31).

Вид графа выбирается на «Основном», потому что он нужен и когда граф рисует студент. Если вид задан, граф сразу приводится к нему (`graphForRules`). Пока вкладка «Граф» открыта, это идёт через `replaceGraph`, поэтому отменяется `Ctrl+Z` в редакторе.

## Файлы

- `model/taskDraft.ts` — черновик задачи (`TaskDraft`) и функции к нему: `createTaskDraft`, `draftTabs` (какие вкладки показать), `draftProblems` (что не заполнено), `graphForRules` (привести граф к виду из правил);
- `ui/TaskConstructorPage.vue` — сама страница с вкладками.
