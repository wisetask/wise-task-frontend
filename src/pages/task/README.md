# task

Страница `/tasks/:id` — решение задачи студентом. Условие задачи и результат проверки рисует виджет `widgets/task-view`, общий с «Моими решениями»; здесь только загрузка, редактор ответа и отправка.

## Как устроена

- Задача загружается запросом `getTask` (`api/getTask.ts`). Граф в нём часто приходит только ссылкой: есть `id`, а вершин и рёбер нет. Тогда `loadFullGraph` из виджета догружает его запросом `getGraphById`, как делал старый фронт. `toTaskView` переводит задачу в вид для страницы.
- Слева условие — `TaskCondition`: категория, название, автор, описание, подсказки (`taskHints`), «Граф задачи» только для просмотра и «Что проверяется» (только названия проверок, без значений: в задаче «найдите хроматическое число» значение и есть ответ).
- Справа «Ваш ответ» — редактор с правилами задачи. Если граф задан, ответ начинается с его копии (`startAnswer`), как в старом фронте и в предпросмотре конструктора. Если графа нет, есть галочка «Ориентированный граф», потому что вида графа у задачи на бэке пока нет. «Начать заново» возвращает ответ к началу.
- «Проверить решение» отправляет `solveTaskGraph` (`api/solveTask.ts`) с ответом через `toGraphInput`. Id решения и графа придумывает фронт (`createId`): на бэке у задач и решений id не генерируется, без него бэк падает с `UNKNOWN`. Результат (`toCheckResult`) показывает `CheckResultNotice`: «Верно!» или список непройденных проверок.
- Как только ответ меняется, результат прошлой проверки пропадает.
- Ошибки: задачи нет (`NOT_FOUND`) — ссылка к списку, остальное — «Повторить». Задачи на написание кода (`TaskImplementation`) пока не открываются.

## Файлы

- `api/getTask.ts`, `api/solveTask.ts` — запрос задачи и мутация проверки;
- `model/errors.ts` — тексты ошибок загрузки и проверки;
- `model/useTask.ts`, `model/useSolve.ts` — загрузка задачи и отправка решения;
- `ui/TaskPage.vue` — сама страница.

## Что дальше

- `pluginsInput` в решении не отправляется (ответы на плагины-строки);
- статистика задачи (`getStatistic`): отправки, решили верно, успешность — как в макете;
- вид графа и «с чего начинается ответ», когда эти поля появятся на бэке.
