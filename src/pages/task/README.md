# task

Страница `/tasks/:id` — решение задачи студентом. Условие задачи и результат проверки рисует виджет `widgets/task-view`, общий с «Моими решениями»; здесь только загрузка, редактор ответа и отправка.

## Как устроена

- Задача загружается запросом `getTask` (`api/getTask.ts`). Граф в нём часто приходит только ссылкой: есть `id`, а вершин и рёбер нет. Тогда `loadFullGraph` из виджета догружает его запросом `getGraphById`, как делал старый фронт. `toTaskView` переводит задачу в вид для страницы.
- Слева условие — `TaskCondition`: категория, название, автор, описание, подсказки (`taskHints`), «Граф задачи» только для просмотра и «Что проверяется» (только названия проверок, без значений: в задаче «найдите хроматическое число» значение и есть ответ).
- Отдельных полос сверху нет: «← Все задачи» стоит в условии (слот `top` у `TaskCondition`), а всё остальное лежит прямо на холсте.
- Справа ответ — редактор с правилами задачи на всю высоту. Если граф задан, ответ начинается с его копии (`startAnswer`), как в старом фронте и в предпросмотре конструктора. Справа сверху, рядом с «Отменить/Вернуть», — галочка «Ориентированный» (только если графа у задачи нет: вида графа на бэке пока нет) и «Заново» (возвращает ответ к началу, стрелка делает оборот).
- Большая круглая кнопка «Проверить решение» справа снизу (или `Ctrl+Enter`) отправляет `solveTaskGraph` (`api/solveTask.ts`) с ответом через `toGraphInput`. Id решения и графа придумывает фронт (`createId`): на бэке у задач и решений id не генерируется, без него бэк падает с `UNKNOWN`. Результат (`toCheckResult`) появляется карточкой `CheckResultNotice` над кнопкой, её можно скрыть крестиком.
- Анимации проверки (`model/checkMotion.ts`): пока ждём ответ, по холсту проходит луч, а на кнопке прыгают три точки. Верно — холст вспыхивает зелёным, из кнопки разлетаются вершины-искры (`burstSparks`), кнопка становится зелёной «Решено верно», заголовок карточки меняется: «Верно!», «В точку!», «Граф сошёлся!» (`successTitle`). Неверно — холст вспыхивает красным, кнопка и карточка встряхиваются.
- Пока идёт проверка, номера в «Что проверяется» по очереди мигают; после ответа пройденные становятся зелёными галочками, непройденные — красными крестиками (`checkMarks`). Если у задачи ошибки скрыты (`isHiddenMistake`), отмечается только та, что показана. При верном ответе по вершинам ответа проходит волна (`playWave` у редактора).
- Пасхалки: если после неверного ответа нажать «Проверить» снова, не поменяв граф, запрос не уходит — кнопка трясётся, а в карточке по очереди появляются шутки (`repeatJoke`). На пустой граф — своя шутка (`emptyGraphNote`). Никаких очков и серий — только шутки.
- Все анимации выключаются переключателем анимаций.
- Как только ответ меняется, результат прошлой проверки пропадает.
- Под условием «Мои попытки» (`ui/TaskAttempts.vue`): последние 8 моих решений этой задачи (`loadTaskAttempts` из `widgets/task-view`), новые сверху, с отметкой верно/неверно и мини-графом (граф попытки грузит `loadSolutionGraph` из `widgets/task-view` и запоминает). Клик загружает граф попытки в ответ через `replaceGraph`, так что `Ctrl+Z` это отменяет. После каждой проверки список обновляется. Порядок «новые сверху» рассчитан на то, что бэк отдаёт решения в порядке отправки — даты у решения на бэке нет.
- После верного ответа в карточке результата есть «Следующая задача»: случайная другая задача из той же категории (`GetNextTasks`, из первых 30; если категории нет — из всех) и ссылка «К списку задач» (`model/useTaskExtras.ts`, `pickNextTask`).
- Если задачу открыли кнопкой «Продолжить с …» из «Моих решений», ответ начинается с переданного графа (`takeHandedAnswer`).
- Открытая задача запоминается в «Недавно открытые» на странице списка (`rememberRecentTask` из `shared/lib/recentTasks.ts`).
- Ошибки: задачи нет (`NOT_FOUND`) — ссылка к списку, остальное — «Повторить». Задачи на написание кода (`TaskImplementation`) пока не открываются.

## Файлы

- `api/getTask.ts`, `api/solveTask.ts` — запрос задачи и мутация проверки;
- `api/getNextTasks.ts`, `model/useTaskExtras.ts`, `model/nextTask.ts` — следующая задача и мои попытки;
- `ui/TaskAttempts.vue` — список попыток;
- `model/checkMotion.ts` — искры, заголовки успеха и шутки для проверки;
- `model/errors.ts` — тексты ошибок загрузки и проверки;
- `model/useTask.ts`, `model/useSolve.ts` — загрузка задачи и отправка решения;
- `ui/TaskPage.vue` — сама страница.

## Что дальше

- `pluginsInput` в решении не отправляется (ответы на плагины-строки);
- статистика задачи (`getStatistic`): отправки, решили верно, успешность — как в макете;
- вид графа и «с чего начинается ответ», когда эти поля появятся на бэке.
