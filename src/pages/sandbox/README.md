# sandbox

Страница `/sandbox`: редактор графа без задачи, чтобы просто порисовать и проверить редактор.

Граф сохраняется в `localStorage` браузера при каждом изменении (ключ `wisetask.sandbox.graph`) и подгружается при следующем открытии страницы. История отмен не сохраняется. Переключатель «Правка | Просмотр» в шапке включает у редактора `readonly`, чтобы проверить, как граф будет выглядеть в превью. «Очистить» сохраняет пустой граф, но её можно отменить через `Ctrl+Z`, пока страница открыта.

«Скачать ▾» открывает список: «Граф (.json)» сохраняет граф в формате бэка (`GraphInput`), «Картинка PNG» и «Картинка SVG» — картинку (о ней ниже). Список — общий `UiMenuButton` из `shared/ui`. «Открыть .json» загружает такой файл обратно. Открытие идёт через `replaceGraph`, поэтому `Ctrl+Z` вернёт прежний граф. Если файл битый, в шапке вместо подсказки появится красное сообщение, что именно не так; если какие-то рёбра пришлось пропустить — тоже. Сообщение пропадает при смене инструмента.

Картинка PNG и SVG — это граф без выделения, на белом фоне, обрезанный по краям графа. Картинку собирает `graphToSvg` из `widgets/graph-editor`, PNG рисуется из неё в два раза крупнее (`svgToPng` с масштабом 2), чтобы была чёткой в отчёте или презентации. Имя файла — по названию графа, как у JSON. В режиме «Просмотр» «Скачать» тоже работает, а «Открыть» скрыто.

«Правила задачи» открывает под шапкой форму `GraphRulesForm`: можно выключить добавление, удаление, подписи, цвета, перемещение и задать вид графа, чтобы посмотреть, как редактор ведёт себя в задаче с ограничениями. Если вид задан, переключатель «Неориентированный | Ориентированный» прячется, а граф сразу приводится к нужному виду (это тоже отменяется `Ctrl+Z`). Открытый из файла граф тоже приводится к нему. Без права удалять пропадает «Очистить». Правила не сохраняются: после перезагрузки снова можно всё.

- `ui/SandboxPage.vue` — сама страница: шапка (слева название и подсказка к инструменту, справа переключатели `UiSegmented` и кнопки) и `GraphEditor` из `widgets/graph-editor` с включёнными подсказками по графу (`analysis`: свойства графа, степени, пасхалки). Смена типа графа и «Очистить» меняют граф через `replaceGraph`, чтобы это попало в историю отмен;
- `lib/savedGraph.ts` — сохранение и загрузка графа. Если в хранилище мусор или граф со сломанными рёбрами, `loadGraph` вернёт `null` и страница начнёт с пустого графа. Если браузер не даёт писать (приватный режим, нет места), `saveGraph` вернёт `false`, а редактор продолжит работать как обычно.
