# relations

Страница `/relations`: модуль «Отношения», режим тренировки. Студент выбирает тип отношения и размер, получает граф и матрицу A и заполняет матрицу степени A^N. Клетки красятся сразу: зелёный — верно, красный — нет.

Демонстрация, проверка, уровни и сохранение прогресса на бэк — в следующих спринтах.

## Из чего собрана

- `RelationsSetup` — выбор типа (любое, симметричное, антисимметричное, асимметричное), числа элементов (3–9) и числа пар. Число пар пересчитывается при смене типа и размера и всегда лежит в границах `minPairs`–`maxPairs`. Под полями — описание выбранного типа. «Сгенерировать» зовёт `generateRelation` и отдаёт странице матрицу и параметры (`GeneratedRelation`). Если связное отношение собрать не вышло, показывается ошибка;
- граф — `GraphCanvas` из `widgets/graph-editor` с `readonly`. Подсветка путей — через его `selection`. При каждом новом отношении холст пересоздаётся (`:key`), чтобы заново вписать граф в окно;
- матрицы — `RelationMatrix` из `widgets/relation-matrix`: A для показа и A^N для ввода. Правильные значения — `power(relation, n, multiplyKind)`;
- переключатели над матрицей — `UiSegmented`: вид умножения (классическое, логическое, тропическое) и степень 2–5. Смена любого сбрасывает ответы и пересчитывает правильные;
- наведение на клетку A^N: `pathsOfLength` даёт пути, на графе они подсвечиваются, а под матрицей пишутся строкой «Из 1 в 4: 1 → 2 → 4, …». Для тропического умножения у каждого пути указан вес (`pathWeight`);
- прогресс «Заполнено 12 из 25, ошибок: 2»; когда матрица заполнена верно, появляется «Верно!» и кнопка «Следующая степень». На степени 5 вместо неё «Сгенерировать новое отношение» с теми же параметрами.

## Граф из матрицы

`relationToGraph(matrix, kind)` — вершины с подписями 1..n и id `v0`, `v1`, …, расставленные по кругу (радиус 140, первая сверху). Ребро на каждую пару `matrix[i][j] !== 0`, id `"e" + i + "-" + j`, петли тоже. Симметричное отношение — неориентированный граф с одним ребром на пару, меньший номер первым.

`pathSelection(paths, kind)` — вершины и рёбра для подсветки списка путей из `pathsOfLength`. Id собираются так же, как в `relationToGraph` (для симметричного `1 → 0` это ребро `e0-1`), иначе рёбра не подсветятся.

## Файлы

- `ui/RelationsPage.vue` — страница;
- `ui/RelationsSetup.vue` — выбор отношения;
- `lib/relationGraph.ts` — граф из матрицы и подсветка путей;
- `lib/relationSetup.ts` — варианты выбора, границы числа пар, тексты описаний, отношение по умолчанию;
- `lib/relationText.ts` — подписи степеней, вид умножения, тексты под матрицей;
- рядом с каждым файлом из `lib` лежат тесты `*.test.ts`.
