# solutions

Страница `/solutions` — «Мои решения»: все мои попытки, собранные по задачам.

- Решения загружаются запросом `getAllTaskSolutions` (`api/getSolutions.ts`) с `authorId` текущего пользователя: все страницы по 100 штук, но не больше 1000 решений (`useSolutionList`, `MAX_PAGES`). Если решений больше, внизу написано, что более старые не видны.
- Попытки собираются в карточки по задачам (`groupSolutions`): одна карточка на задачу, сверху задачи с самой свежей попыткой. Даты у решения на бэке нет, поэтому «свежесть» — это порядок, в котором бэк отдаёт решения (считаем, что в порядке отправки). Решения удалённых задач идут отдельными карточками «Задача удалена».
- Карточка: «Решена» или «Не решена», категория своим цветом (`categoryColor` из `shared/lib`), название (ссылка на последнюю попытку), «Решена с 3-й попытки · 5 попыток» (`groupSummary`), цепочка попыток и мини-граф задачи (`TaskGraphThumb`). Кнопки: «Последняя попытка», «Решить заново» и «Продолжить с последнего графа» — открывает задачу, и ответ сразу начинается с графа последней попытки (`handOffAnswer` из `widgets/task-view`).
- Цепочка попыток (`ui/AttemptPath.vue`): кружки по порядку, слева старые, зелёные — верные, красные — неверные, у последней пульсирует кольцо. Видно последние 12 (`shownDots`), остальные — «+N». Каждый кружок ведёт на свою попытку.
- Сверху поиск по названию и переключатель «Все / Решённые / Не решённые» (`UiSegmented`), фильтрует фронт (`groupMatches`). «Найдено 12 задач, 40 попыток». Карточки показываются по 20, дальше догружаются при прокрутке.
- Если подержать курсор на карточке, рядом всплывает предпросмотр (`ui/SolutionPreviewPopover.vue`): граф последнего ответа крупно (`loadSolutionGraph`) и итог по задаче.
- По бокам (на широком экране):
  - слева «Карта задач» (`ui/TaskMap.vue`, `taskMapLayout`): каждая задача, которую пробовали (до 40 самых свежих), — вершина, разложенная по спирали. Зелёные — решённые, они мягко светятся; оранжевые — нерешённые. Чем больше попыток, тем крупнее вершина. Задачи одной категории связаны рёбрами. Вершины медленно плавают. Наведение показывает название и число попыток, клик прокручивает список к этой задаче и подсвечивает карточку (если её скрыл фильтр, фильтр сбрасывается). Когда выбрана категория, остальные вершины тускнеют;
  - ниже «Категории» из моих задач — выбранную подсвечивает плашка, которая переезжает от одной категории к другой; ниже «Обозначения»;
  - справа «Стоит вернуться» — до 4 нерешённых задач с самым большим числом попыток (`stuckGroups`), рамка карточки переливается. У каждой задачи «звезда попыток» (`ui/AttemptStar.vue`, `starLeaves`) — граф-звезда K₁,ₙ: в центре задача, листья — попытки (красные неверные, зелёные верные), звезда медленно вращается, последний лист пульсирует;
  - «Лента попыток» (`ui/AttemptFeed.vue`, `recentFeed`): 8 последних попыток по всем задачам, по ленте проходит луч, у самой свежей пульсирует точка;
  - «Подсказка» (`ui/SolutionsTips.vue`, `model/tips.ts`) — советы по странице меняются сами раз в 9 секунд.
- Наведение на карточку подсвечивает её вершину на карте и её категорию слева.
- Фон страницы — живой граф (`ui/SolutionsBackdrop.vue`, `model/backdropGraph.ts`): 32 вершины по всему экрану, каждая связана с тремя ближайшими. Раз в несколько секунд из случайной вершины запускается поиск в ширину: вершины вспыхивают слоями, рёбра дерева обхода подсвечиваются, затем до самой дальней вершины прорисовывается зелёный кратчайший путь, и по нему пробегает огонёк. Граф чуть сдвигается за курсором. Пока вкладка скрыта, новые волны не запускаются. В «Спокойном режиме» фона нет.
- В шапке — цепочка попыток-вершин: красные, по которым бежит огонёк, и зелёная в конце.
- Без входа страница предлагает войти. Пока профиль загружается, запрос не отправляется.
- Никаких очков и серий: только статус задач и попытки.

## Файлы

- `api/getSolutions.ts` — запрос `getAllTaskSolutions`;
- `model/solutionList.ts` — функции без Vue: `toSolutionItem`, `groupSolutions`, `groupMatches`, `groupCategories`, `stuckGroups`, `shownDots`, `groupSummary`, `attemptsText`, `groupsFoundText`, тексты пустого списка и ошибок;
- `model/useSolutionList.ts` — загрузка всех моих решений;
- `model/tips.ts` — подсказки;
- `model/sideViews.ts` — расчёты для боковых панелей: `taskMapLayout`, `starLeaves`, `recentFeed`;
- `model/backdropGraph.ts` — живой фон: `backdropPoints`, `nearestEdges`, `breadthFirst`, `farthestNode`, `pathTo`, `pathLine`;
- `ui/SolutionsPage.vue` — страница, `ui/AttemptPath.vue` — цепочка попыток, `ui/SolutionPreviewPopover.vue` — предпросмотр, `ui/SolutionsTips.vue` — подсказки, `ui/TaskMap.vue` — карта задач, `ui/AttemptStar.vue` — звезда попыток, `ui/SolutionsBackdrop.vue` — живой фон, `ui/AttemptFeed.vue` — лента попыток.
