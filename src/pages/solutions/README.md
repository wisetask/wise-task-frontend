# solutions

Страница `/solutions` — «Мои решения»: решения текущего пользователя с бэка.

- Решения загружаются запросом `getAllTaskSolutions` (`api/getSolutions.ts`) с `authorId` текущего пользователя (`useUserStore().user.id`), по 20 штук (`PAGE_SIZE`), внизу «Показать ещё».
- Сверху переключатель «Все / Верные / Неверные». «Верные» фильтрует бэк (`isCorrect: true`). Бэк не умеет отдавать только неверные: `isCorrect: false` он понимает как «без фильтра». Поэтому для «Неверных» загружаются все решения, а верные отбрасываются на фронте (`keepForFilter`), а «Найдено» считается как «все минус верные» (`wrongCount`): при первой загрузке уходит ещё один маленький запрос с `isCorrect: true` и `pageSize: 1`, только ради числа верных. На странице может прийти меньше 20 строк, «Показать ещё» догружает дальше.
- В строке: категория и название задачи и отметка «Верно» или «Неверно». Если задачу удалили, пишется «Задача удалена». Клик открывает решение `/solutions/:id` (`pages/solution`).
- Без входа страница предлагает войти. Пока профиль загружается, запрос не отправляется: он уходит, как только появляется id пользователя.
- Сортировки по времени нет: бэк не отдаёт, когда отправлено решение.

## Файлы

- `api/getSolutions.ts` — запрос `getAllTaskSolutions`;
- `model/solutionList.ts` — функции без Vue: `toSolutionItem`, `filterToCorrect`, `emptySolutionsText`, `loadSolutionsErrorText`, названия фильтров;
- `model/useSolutionList.ts` — загрузка: `search` с первой страницы, `loadMore` следующую. Ответ на устаревший запрос отбрасывается;
- `ui/SolutionsPage.vue` — сама страница.

После изменения запроса нужно перезапустить `npm run codegen`.
