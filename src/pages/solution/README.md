# solution

Страница `/solutions/:id` — просмотр своего решения.

- Решение загружается запросом `getTaskSolution` (`api/getSolution.ts`) вместе с задачей. Граф задачи и граф решения бэк может прислать только ссылкой, тогда их догружает `tryLoadFullGraph` из `widgets/task-view`. Если граф по ссылке не нашёлся, страница всё равно открывается: без графа задачи или с надписью «Граф решения не нашёлся на сервере».
- Устроена как страница задачи. Слева условие (`TaskCondition`, без подсказок): «← Мои решения» сверху, в «Что проверяется» галочки и крестики по результату (`checkMarks`). Справа на всю высоту — граф ответа только для просмотра, карточка результата (`CheckResultNotice`, «Решение верное» / «Решение неверное») и вспышка зелёным или красным при открытии.
- Слева сверху на холсте — «Попытка 3 из 5» со стрелками и точками попыток по этой задаче (`loadTaskAttempts`, `attemptPlace`). Листать можно и клавишами ← и →. Страница при этом не пересоздаётся (у маршрута `meta.samePage`, `AppLayout` не меняет ключ), а предыдущий ответ остаётся на экране, пока грузится следующий: холст плавно переводит один граф в другой (`expectJump`) — общие вершины переезжают, остальное гаснет и появляется.
- Справа сверху:
  - «Что я изменил» (если у задачи есть граф) — вместо холста картинка разницы (`ui/GraphDiffView.vue`, `graphDiff`): добавленные вершины и рёбра зелёные, удалённые — красным пунктиром, перекрашенные вершины с оранжевым кольцом. Вершины сравниваются по подписям, рёбра — по подписям концов. Внизу слева итог словами (`diffSummary`): «Добавлено: 2 вершины и 1 ребро».
  - «Продолжить с этого графа» — открывает задачу, и ответ начинается с этого графа (`handOffAnswer`).
  - «Решить заново» — задача с начала.
- Решения задач на код и решения удалённых задач пока не открываются. Если решения нет (`NOT_FOUND`), есть ссылка к списку, на другие ошибки — «Повторить».

## Файлы

- `api/getSolution.ts` — запрос `getTaskSolution`;
- `model/useSolution.ts` — загрузка решения: задача (`TaskView`), граф решения и результат проверки. При переходе к другой попытке старые данные остаются, пока не придут новые;
- `model/graphDiff.ts` — `graphDiff`, `diffSummary`, `attemptPlace`;
- `model/errors.ts` — тексты ошибок;
- `ui/SolutionPage.vue` — страница, `ui/GraphDiffView.vue` — картинка «Что я изменил».
