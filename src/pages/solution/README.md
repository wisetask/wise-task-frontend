# solution

Страница `/solutions/:id` — просмотр своего решения.

- Решение загружается запросом `getTaskSolution` (`api/getSolution.ts`) вместе с задачей. Граф задачи и граф решения бэк может прислать только ссылкой, тогда их догружает `tryLoadFullGraph` из `widgets/task-view`. Если граф по ссылке не нашёлся (сервис графов сохраняет граф под своим id, а не под тем, что прислал фронт), страница всё равно открывается: без графа задачи или с надписью «Граф решения не нашёлся на сервере».
- Слева условие задачи (`TaskCondition`, без подсказок про ответ). Справа «Ваше решение»: результат проверки (карточка `CheckResultNotice` с заголовками «Решение верное» / «Решение неверное» и списком непройденных проверок) и граф решения только для просмотра.
- Кнопка «Решить ещё раз» ведёт на страницу задачи `/tasks/:id`.
- Решения задач на код и решения удалённых задач пока не открываются. Если решения нет (`NOT_FOUND`), есть ссылка к списку, на другие ошибки — «Повторить».

## Файлы

- `api/getSolution.ts` — запрос `getTaskSolution`;
- `model/useSolution.ts` — загрузка решения: задача (`TaskView`), граф решения и результат проверки;
- `model/errors.ts` — тексты ошибок;
- `ui/SolutionPage.vue` — сама страница.
