# tasks

Страница `/tasks` — «Задачи»: список задач на граф с бэка.

- Задачи загружаются запросом `getAllTasks` (`api/getTasks.ts`) по 20 штук (`PAGE_SIZE`), только задачи на граф (`taskType: GRAPH`). Если на бэке есть ещё, внизу кнопка «Показать ещё».
- Сверху строка поиска (прилипает к верху при прокрутке): слева название, справа категория. Ищет сама через 0,35 секунды после того, как перестали печатать (`Enter` — сразу); пока идёт запрос, в поле крутится значок, у заполненного поля есть крестик. Фильтрует сам бэк (`TaskFilterInput`), пустые поля не отправляются. Поиск сохраняется в адресе (`?q=…&category=…`, `filterFromQuery` и `queryFromFilter`), поэтому после возврата из задачи он на месте, и ссылкой на поиск можно поделиться.
- Под строкой поиска — до 8 частых категорий из уже загруженных задач (`popularCategories`). Клик ставит категорию в поиск, повторный клик убирает.
- «Найдено 1655 задач, показано 40» (`foundText` склоняет слово). Пока список грузится впервые, вместо карточек мерцающие заготовки. Внизу списка задачи догружаются сами, когда до конца остаётся 300px (`IntersectionObserver`); кнопка «Показать ещё» остаётся на случай, если автоподгрузка не сработала.
- Карточка задачи: категория плашкой, пометка «Видна не всем» с перечёркнутым глазом, название (найденный текст подсвечен — `highlightParts`), начало описания в две строки (`shortDescription`, до 160 символов, обрезается по словам), автор с инициалами. При наведении карточка приподнимается, слева появляется синяя полоска, справа стрелка. Карточки появляются по очереди. Клик ведёт на страницу решения `/tasks/:id` (`pages/task`).
- Автору и админу справа от заголовка видна ссылка «Создать задачу» в конструктор. Рядом с заголовком маленький живой граф: рёбра прорисовываются, вершины появляются по очереди, по рёбрам бегает огонёк.
- Анимации поиска: в пустом поле подсказка сама «печатает» примеры — короткие названия уже загруженных задач (`model/searchMotion.ts`: `placeholderExamples`, `placeholderFrame`), в фокусе подсказка обычная. Пока идёт запрос, лупа «ищет», а под строкой бежит полоска. Число в «Найдено N задач» плавно докручивается до нового (`countStep`). Когда строка поиска прилипла к верху, у неё появляется тень. Старый список во время поиска тускнеет, новый сменяет его плавно (`generation` из `useTaskList` растёт на каждой первой странице).
- Анимации карточек: появляются по очереди, за курсором по карточке идёт мягкий свет, подсветка найденного текста «закрашивается» слева направо, кружок автора загорается. Пока догружается следующая страница, внизу прыгают три вершины. После долгой прокрутки справа снизу появляется кнопка «Наверх».
- По бокам (только на широком экране, от 1280px; уже — их нет, а категории остаются кнопками под поиском):
  - слева «Категории»: «Все задачи» и до 14 частых категорий из загруженных задач, у каждой цветная точка, выбранная подсвечена полоской;
  - справа «Случайная задача»: кубик крутится, `pickRandom` из `useTaskList` берёт одну случайную задачу из всех найденных (страница размером 1 со случайным номером), и открывается её страница. Если запрос не удался, берётся случайная из уже загруженных;
  - справа «Недавно открытые» — последние 6 задач, которые открывали на этом компьютере (`shared/lib/recentTasks.ts`, их записывает страница задачи), с кнопкой «Очистить»;
  - справа «Быстрые клавиши».
- За шапкой медленно дрейфует бледное «созвездие» (`ui/TasksConstellation.vue`, расчёт в `model/constellation.ts`): близкие точки соединяются рёбрами, а к курсору тянутся рёбра от ближайших точек.
- Фон всей страницы — «витрина задач» (`ui/TasksBackdrop.vue`). Под списком лежит бледный треугольный граф, и он по очереди «решает» классические задачи (`SHOWCASE_ORDER`): жадную раскраску (вершина пробует цвета по порядку, отвергнутые вспыхивают красным кольцом), минимальное остовное дерево Краскала (рёбра, которые дали бы цикл, мигают красным), паросочетание и гамильтонов путь змейкой. Внизу слева подпись, что сейчас решается и с каким результатом. Если выбрана категория, по названию которой понятна тема (`showcaseForCategory`: раскраска, деревья, паросочетания, гамильтоновы циклы), фон показывает только эту задачу. Фон есть, только когда анимации включены. Чтобы фон был под содержимым, у `.tasks-page` стоит `isolation: isolate`, а у фона `z-index: -1`.
- Карточки чуть наклоняются за курсором (`tiltAngles`, до 3°). Справа в карточке мини-граф задачи (`TaskGraphThumb` из `widgets/task-view`): граф грузится отдельным запросом, только когда карточка доезжает до экрана; сам список графов не запрашивает, поэтому ошибка с графом не ломает список. При наведении рёбра мини-графа прорисовываются заново. Пустых графов не показываем.
- Клик по карточке (и по «Недавно открытым», и «Случайная задача») раскрывает её в страницу задачи: `expandGhost` из `shared/lib`.
- Пасхалки: набрать на клавиатуре «граф» (не в поле ввода, на любой раскладке — сравниваются клавиши `GRAPH_CODE`) — карточки соединяются рёбрами в один граф и подпрыгивают (`chainLinks`). Поиск со словом «Кёнигсберг» или пустой поиск со словом «Эйлер» — сверху появляется сцена с кёнигсбергскими мостами (`ui/KonigsbergScene.vue`, `wantsKonigsberg`): огонёк проходит пять мостов и застревает. Если торопить кубик «Случайной задачи», он подпрыгивает и просит не торопить.
- У каждой категории свой цвет (`categoryColor` в `model/taskMarks.ts`: один и тот же цвет для одного названия): плашка в карточке, полоска слева, рамка при наведении и точка в боковой панели совпадают.
- Отметки «Решена» (зелёная галочка) и «Были попытки» (оранжевая точка) — по моим решениям: `useTaskMarks` загружает их запросом `GetMyTaskMarks` (`api/getMyMarks.ts`, до 10 страниц по 100), `taskMarks` превращает в «задача → отметка». Верное решение важнее неверных. В «Недавно открытых» решённые задачи отмечены галочкой. Слева под категориями — «Обозначения». Это просто статус задачи, без очков и счётчиков.
- Если подержать курсор на карточке полсекунды, рядом с ней всплывает предпросмотр (`ui/TaskPreviewPopover.vue`): категория, название, крупный граф с подписями и весами и полное условие. Место выбирает `popoverPlace`: справа от карточки, если там хватает места, иначе слева; если места нет нигде (узкий экран), предпросмотра нет. Пропадает при уходе курсора, клике и прокрутке.
- Справа «Факт о графах» (`ui/GraphFactCard.vue`, `model/graphFacts.ts`): короткий факт из теории графов с маленькой картинкой, которая прорисовывается. Факт меняется сам раз в 15 секунд и по «Ещё факт». Рамка «Случайной задачи» переливается, боковые карточки приподнимаются при наведении.
- Клавиши: `/` в любом месте страницы ставит курсор в поиск (в поле подсказка `/`), `Esc` в поиске стирает название, а в пустом поле убирает курсор.
- Всё это выключается переключателем анимаций (`data-motion="off"`, `motionAllowed()`), бесконечные анимации выключаются и при системном «уменьшить движение».
- Если загрузить не вышло, вместо списка ошибка и «Повторить». Если задач нет, страница пишет об этом по-разному для пустого фильтра и для поиска (с картинкой графа, у которого «потерялась» вершина), а при поиске предлагает «Сбросить поиск».

## Файлы

- `api/getTasks.ts` — запрос `getAllTasks`;
- `model/taskList.ts` — функции без Vue: `toListItem` (задача с бэка → карточка), `shortDescription`, `authorName`, `filterValue`, `emptyListText`, `loadErrorText`, а для поиска `highlightParts`, `plural`, `foundText`, `popularCategories`, `filterFromQuery`, `queryFromFilter`;
- `model/searchMotion.ts` — функции для анимаций без Vue: `countStep` (промежуточное число при докрутке), `placeholderExamples` и `placeholderFrame` («печатающаяся» подсказка), `tiltAngles`, `pushCode`/`codeMatches`, `chainLinks`, `wantsKonigsberg`;
- `api/getMyMarks.ts`, `model/useTaskMarks.ts`, `model/taskMarks.ts` — отметки «Решена» / «Были попытки» и цвета категорий;
- `model/graphFacts.ts`, `ui/GraphFactCard.vue` — факты о графах;
- `ui/TaskPreviewPopover.vue` — предпросмотр задачи при наведении;
- `model/constellation.ts` — точки созвездия: `createStars`, `moveStars` (отскакивают от краёв), `starLinks`;
- `model/coloringBackdrop.ts` — граф для фона и раскраска: `latticePoints`, `latticeEdges`, `neighbourLists`, `paintOrder` (обход в ширину), `greedyColoring`, `isProperColoring`, `colorsText`;
- `model/showcase.ts` — задачи для фона: `coloringRun`, `treeRun`, `matchingRun`, `hamiltonRun`, `buildRun`, `showcaseForCategory`, `nextKind`. Каждая возвращает, какие вершины и рёбра подсветить и когда;
- `ui/TasksBackdrop.vue` — фон «витрина задач»;
- `ui/TasksConstellation.vue`, `ui/KonigsbergScene.vue` — созвездие и сцена с мостами;
- `model/useTaskList.ts` — загрузка: `search(filter)` начинает с первой страницы, `loadMore(filter)` добавляет следующую, `generation` считает пришедшие первые страницы, `pickRandom(filter)` достаёт одну случайную задачу. Если ответ на старый запрос пришёл позже нового, он отбрасывается;
- `ui/TasksPage.vue` — сама страница.

После изменения запроса нужно перезапустить `npm run codegen`.
