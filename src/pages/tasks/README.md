# tasks

Страница `/tasks` — «Задачи»: список задач на граф с бэка.

- Задачи загружаются запросом `getAllTasks` (`api/getTasks.ts`) по 20 штук (`PAGE_SIZE`), только задачи на граф (`taskType: GRAPH`). Если на бэке есть ещё, внизу кнопка «Показать ещё».
- Сверху поиск по названию и категории. Фильтрует сам бэк (`TaskFilterInput`), пустые поля не отправляются. «Показать ещё» догружает по тому фильтру, по которому искали, даже если поля уже поменяли.
- Карточка задачи: категория, название, начало описания (`shortDescription`, до 160 символов, обрезается по словам), автор и пометка «Видна не всем» у непубличных задач. Клик ведёт на страницу решения `/tasks/:id` (`pages/task`).
- Автору и админу справа от заголовка видна ссылка «Создать задачу» в конструктор.
- Если загрузить не вышло, вместо списка ошибка и «Повторить». Если задач нет, страница пишет об этом по-разному для пустого фильтра и для поиска.

## Файлы

- `api/getTasks.ts` — запрос `getAllTasks`;
- `model/taskList.ts` — функции без Vue: `toListItem` (задача с бэка → карточка), `shortDescription`, `authorName`, `filterValue`, `emptyListText`, `loadErrorText`;
- `model/useTaskList.ts` — загрузка: `search(filter)` начинает с первой страницы, `loadMore(filter)` добавляет следующую. Если ответ на старый запрос пришёл позже нового, он отбрасывается;
- `ui/TasksPage.vue` — сама страница.

После изменения запроса нужно перезапустить `npm run codegen`.
