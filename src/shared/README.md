# shared

Общий код без бизнес-логики:

- `config/env.ts` — адреса API из `.env`;
- `lib/createId.ts` — генерация id;
- `lib/downloadBlob.ts` — скачать готовый `Blob` как файл через временную ссылку;
- `lib/downloadText.ts` — скачать строку как файл (обёртка над `downloadBlob`);
- `lib/svgToPng.ts` — нарисовать SVG-строку на `canvas` и отдать PNG. Масштаб `scale` увеличивает картинку, например `2` для чётких картинок на ретина-экранах. Работает только в браузере;
- `ui/` — общие компоненты: кнопка, поле ввода, галочка;
- `api/` — Apollo-клиент, токен и codegen.

Ни из какого другого слоя не импортирует.
