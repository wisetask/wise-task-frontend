# shared/lib

Мелкие помощники без интерфейса.

- `createId.ts` — новый id (UUID) для объектов, которые фронт создаёт сам.
- `downloadBlob.ts`, `downloadText.ts` — скачать файл из браузера.
- `svgToPng.ts` — превратить SVG-картинку в PNG.
- `motion.ts` — можно ли сейчас анимировать.
- `expandGhost.ts` — «раскрытие» карточки в страницу: `expandGhost(откуда, куда, название)` кладёт поверх страницы простой блок размером с карточку, растягивает его до области страницы (Web Animations), переносит название к месту заголовка и плавно гасит. Это обычный элемент, а не снимок страницы, поэтому не ломается на слабых видеокартах. Список задач вызывает его при клике по карточке, по «Недавно открытым» и по «Случайной задаче». Не играет, если ссылку открывают в новой вкладке (`canExpand`) и в «Спокойном режиме». Стили — `.expand-ghost` в `app/styles.css`.
- `recentTasks.ts` — недавно открытые задачи в `localStorage` (`wisetask.recentTasks`, до 6 штук): страница задачи вызывает `rememberRecentTask`, список задач показывает `readRecentTasks`, «Очистить» — `forgetRecentTasks`. Испорченные записи пропускаются (`parseRecentTasks`).

## motion.ts

`motionAllowed()` возвращает `false`, если пользователь выключил анимации кнопкой `MotionToggle` (`features/motion-switch`) или в системе включено «уменьшить движение». Это проверяют все анимации, которые делаются из кода: плавный масштаб и авторасположение в редакторе графа, пасхалки, бегущая точка на ориентированных рёбрах. Если анимировать нельзя, они сразу показывают итог.

`setMotionOff(true)` ставит на `<html>` атрибут `data-motion="off"` и запоминает выбор в `localStorage` (`wisetask.motion`). По этому атрибуту `app/styles.css` выключает все CSS-анимации и переходы на сайте. `isMotionOff()` — включён ли сейчас этот режим; значение реактивное, поэтому `computed` с ним пересчитываются сами.
